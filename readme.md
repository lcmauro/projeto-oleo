# Sistema de Captação de Óleo para Reciclagem

Projeto desenvolvido em Linguagem C.

## Funcionalidades

- Importação de lotes
- Exclusão de lotes
- Geração de relatório geral
- Geração de relatório mensal
- Backup automático antes da exclusão
- Armazenamento em arquivo binário

## Compilação

```bash
gcc main.c coletas.c pss.c -o projeto
```

## Execução

```bash
./projeto
```
